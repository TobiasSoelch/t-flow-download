# T-Flow by talQit – Download

Diktat per Hotkey für Windows.

**Installieren:** Unter [Releases](../../releases/latest) die Datei `T-Flow-Setup-….exe` herunterladen und doppelklicken.

- Windows zeigt beim ersten Mal eventuell „Der Computer wurde durch Windows geschützt“. Dann auf **Weitere Informationen** und **Trotzdem ausführen** klicken.
- Nach dem Start den OpenAI-Schlüssel im Setup eintragen.
- Neue Versionen meldet T-Flow selbst (Rechtsklick aufs Symbol in der Taskleiste → Update installieren).
